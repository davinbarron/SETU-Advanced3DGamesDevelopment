# Week 6-B: Azure Function Baseline

## Goal

Create and publish first Azure Function for Photon custom auth, then configure Photon with the function URL.

## What Was Completed

- Created Azure Function `Auth`
- Published function to Azure
- Retrieved Function URL from Azure Portal
- Added Function URL to Photon custom authentication settings
